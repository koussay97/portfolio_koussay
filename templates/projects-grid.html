Joel Apps

Architecting a closed-loop gig-economy ecosystem within a scalable Flutter monorepo.

Mission & Constraints

Joel Apps is an enterprise service fulfillment platform. The primary constraint was moving beyond a standard "happy path" gig-app to build a dynamic transaction state machine managing pre-job logistics, automated invoicing, and complex edge-case lifecycle events (cancellations, price renegotiations) autonomously.

System Architecture

Sept 2025 – Present
Domain & Architecture

To manage complex transaction lifecycles without coupling UI to business logic, the system was built as a Flutter monorepo using Melos, enforcing strict feature-level modular boundaries.

Implementation Decisions
  • State-Agnostic UI: Developed a decoupled UI system utilizing custom Flutter Hooks and Widgetbook for isolated testing.
  • Custom State Management: Built a dedicated proprietary package (Effectum) to handle localized gig-lifecycle edge cases.
  • Security: Backend integration secured strictly via Firebase Auth SSO.
Outcomes & Delivery

By heavily investing in contract-first design, the MVP was successfully engineered, automated via Fastlane and GitHub Actions, and delivered to production in under 5 months.

Lifebonder

Cross-platform social network architecture prioritizing local-first data sync and WebRTC privacy.

Mission & Constraints

Lifebonder required a highly responsive, privacy-centric communication platform. The technical constraint was maintaining UI fluidity while orchestrating heavy local database syncing, AI recommendation data telemetry, and end-to-end encrypted real-time video/chat pipelines across offline and online states.

System Architecture

May 2025 – Sept 2025
Domain & Architecture

Led an architectural refactoring enforcing strict Clean Architecture and Domain-Driven Design. This decoupled the real-time communication protocols from the presentation layer.

Implementation Decisions

  • Telemetry: Integrated session heat maps feeding an AI recommendation engine without blocking the UI thread.
Outcomes & Delivery

Significantly enhanced UI responsiveness during complex offline-first states and consolidated multi-environment CI/CD deployment pipelines.

Mushir App

Engineering a custom regional payment gateway package within an on-demand legal marketplace.

Mission & Constraints

Mushir modernizes access to legal representation via a curated marketplace. The critical engineering constraint was processing payments natively using ClickPay.sa, which completely lacked an official Android/iOS SDK plugin, alongside resolving severe structural flaws in the existing deep-linking and authentication systems.

System Architecture

Aug 2024 – May 2025
Domain & Architecture

The system acts as a secure intermediary for legal counsel. Re-engineered the routing architecture to handle complex SSO flows and specific legal-package deep links seamlessly across states.

Implementation Decisions
  • Custom Payment Engine: Bypassed the missing SDK by engineering a dedicated Flutter package integrating ClickPay.sa via embedded WebViews, governed by BLoC and RxDart.
  • State Safety: Rebuilt the authentication flow to eliminate race conditions during SSO callbacks and deep link interceptions.
  • Geolocation: Implemented map integration for static office locations while preserving client privacy boundaries.
Outcomes & Delivery

Successfully deployed the bespoke payment package, automating weekly payouts and fully resolving critical authentication and routing flaws preventing app launch.

Electrical Concentrators

Multi-window IoT desktop architecture rendering high-density real-time MQTT telemetry.

Mission & Constraints

An Enterprise Industrial IoT Maintenance Workstation for utility grid engineers. The constraint was rendering live, high-frequency telemetry (voltage, current, active power) for hundreds of connected meters concurrently across multiple detached floating desktop windows without triggering race conditions or UI thread locks.

System Architecture

May 2024 – Aug 2024
Domain & Architecture

Engineered a multi-session desktop architecture using a central command hub that orchestrates detached floating windows, allowing engineers to manage independent grid node sessions simultaneously.

Implementation Decisions
  • Native API Integration: Developed custom C++ implementations to bridge Flutter with native Windows APIs, eliminating multi-threading race conditions.
  • Real-Time MQTT: Architected a high-throughput MQTT client capable of consuming and parsing massive live data streams with extreme precision.
  • Render Optimization: Modified Syncfusion DataGrids to handle high-density tabular rendering without dropping frames during data injection.
Outcomes & Delivery

Delivered a highly stable, protocol-level command execution grid for direct IoT device intervention, alongside robust diagnostic CSV/Excel export tools.
