AI-Driven Recruitment / Spectrum Analysis

Architecture Experiment

An architectural exploration of using LLMs as replaceable contract components. The core concept replaces binary "good/bad" candidate evaluations with a dimensional spectrum assessment (leadership, technical depth, adaptability) mapping to contextual business needs.

Generative AI RPG Mechanics

AI Systems Exploration

A research project integrating generative AI into real-time role-playing game state machines. Explores dynamic narrative branching and stateful NPC memory retention without blocking the main rendering thread.
